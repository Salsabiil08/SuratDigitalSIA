# Referensi UI SIADocs

File `*.dc.html` adalah contoh tampilan (HTML dan CSS) yang sudah disepakati: Login, Dashboard (`Main`), Surat Saya (`Surat`), Buat Surat (`Buat`), Detail Surat (`Detail`), Persetujuan Masuk (`Persetujuan`), dan Log History (`LogHistory`). Tag `<x-dc>` dan `<helmet>` hanya pembungkus kanvas desain, abaikan. Ambil struktur HTML, kelas CSS, warna, dan teks. Logo ada di `assets/logo.png`.

Catatan R.04: contoh ini dibuat sebelum R.04. Layar Ambil Nomor belum ada, dan elemen distribusi pada Detail harus dihapus. Ikuti `ANTIGRAVITY.md` bagian UI.
